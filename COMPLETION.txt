🚀 DÉMARRAGE RAPIDE (10 minutes)
═══════════════════════════════════════════════════════════════════════════════

1. LIRE (2 min)
   $ cat START_HERE.md

2. CRÉER SUPABASE (2 min)
   → supabase.com
   → Créer projet

3. SQL SCRIPT (1 min)
   → Copier supabase-setup.sql dans Supabase SQL Editor
   → Run

4. CONFIGURER (1 min)
   $ cp .env.example .env.local
   # Ajouter clés Supabase

5. INSTALLER (1 min)
   $ pnpm install

6. LANCER (1 min)
   $ pnpm dev
   → http://localhost:3000

7. TESTER (1 min)
   → S'inscrire
   → Ajouter équipes
   → Créer matchs

8. DÉPLOYER (1 min)
   → Git push
   → Vercel deploy
